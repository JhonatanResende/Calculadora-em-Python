# 🧮 Calculadora Python

Calculadora de terminal desenvolvida em Python com operações matemáticas básicas e funcionalidades extras.

---

# 🚀 Funcionalidades

✅ Soma  
✅ Subtração  
✅ Multiplicação  
✅ Divisão  
✅ Raiz quadrada  
✅ Logaritmo na base 2  
✅ Resultado colorido no terminal  
✅ Tratamento de erros  
✅ Menu interativo  

---

# 🛠️ Tecnologias utilizadas

- 🐍 Python
- 🎨 Termcolor

---

# ▶️ Como executar o projeto

## 📥 Clone o repositório

```bash
git clone https://github.com/JhonatanResende/Calculadora-em-Python
```

---

## 📂 Acesse a pasta do projeto

```bash
cd Calculadora-em-Python
```

---

## 🧪 Crie e ative o ambiente virtual

### 🪟 Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

---

## 📦 Instale as dependências

```bash
pip install -r requirements.txt
```

---

## ▶️ Execute o projeto

```bash
python calculadora.py
```
